# Exploratory Data Analysis and Prediction of Iris Species

## 📌 Project Overview

This project focuses on exploring the Iris dataset and predicting the species of an Iris flower using the **K-Nearest Neighbors (KNN)** algorithm.

The project includes basic data analysis, data visualization, data preprocessing, and classification using KNN.

## 🎯 Objectives

* Explore the Iris dataset.
* Understand the features of Iris flowers.
* Visualize relationships between different features.
* Preprocess the data using feature scaling.
* Build a KNN classification model.
* Predict the species of a new Iris flower.

## 📊 Dataset

The project uses the **Iris dataset** provided by Scikit-learn.

The dataset contains three species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

### Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## 🔍 Exploratory Data Analysis

Basic data visualization is performed using graphs to understand the dataset.

The project includes:

* Sepal Length vs Sepal Width scatter plot
* Average Petal Length bar graph

These visualizations help in understanding the differences between the three Iris species.

## 🤖 Machine Learning Algorithm

### K-Nearest Neighbors (KNN)

KNN is a supervised machine learning classification algorithm.

In this project:

* The dataset is divided into training and testing sets.
* Features are standardized using `StandardScaler`.
* A KNN classifier is created with `n_neighbors = 5`.
* The model is trained using the training data.
* The trained model predicts the Iris species of test samples and new user input.
